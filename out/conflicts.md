# 근거 충돌 목록 (conflicts.md)

서로 다른 값을 말하는 근거쌍과, 보고서가 이를 어떻게 처리했는지를 기록한다.
채택 원칙은 `CLAUDE.md` 규칙 3에 따른다 — **1차 소스 > 2차 소스**, **등록정보·공시·원논문 > 보도자료·언론**.
"보고서 처리" 열이 ✗ 인 항목은 반영이 필요한 항목이며, 본 감사에서 전부 반영했다.

| **B** | [R635] TESLA 독립 검증 코호트: 310개 중 4개 = **1.3%** |
| **C** | [R608][R661] 임상에서 실제 투여된 항원: **11–16%** (Rojas 230개 중 25개, Cafri 15.7%) |

| **보고서 처리** | ✓ §1.3에서 세 값을 분모와 함께 구분 제시하고, 흔히 인용되는 "precision 0.70"이 **이미 상위 랭크된 608개 내부 값**임을 명시 |
